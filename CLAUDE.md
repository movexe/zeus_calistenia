## 🎬 2. ScrollCraft Engine Standards

### The 8 Structural Page Grammars
Never default to a generic landing page. Choose one distinct grammar per build:
1. **Filmic One-Shot**: A single camera/viewport that transforms continuously as the user scrolls.
2. **Chaptered Editorial**: Magazine-grade rhythm, full-bleed imagery, asymmetric typographic blocks.
3. **Live Surface**: An interactive canvas reacting simultaneously to scroll position and cursor vectors.
4. **Continuous World**: Smooth camera flight through an unbroken, persistent 3D/2.5D visual environment.
5. **Typographic Poster**: Monumental headline scale, kinetic type scrubbing, strict typographic discipline.
6. **Gallery Stage**: Horizontal card trains, sticky display pedestals, curated visual reveals.
7. **Split Stage**: Fixed left narrative anchor with dynamic right media rail (or vice-versa).
8. **Rhythmic Cutlist**: Fast-tempo, high-contrast visual cuts with alternating tension and release.

### Anti-Generic AI "Taste Floor" (ScrollCraft Principles)
- ❌ **Forbidden AI Tropes**: No uniform 3-card feature grids with identical icons, no decorative `01 / 06` numbers without functional purpose, no fake purple-cyan gradient text on every headline, no generic "Lorem Ipsum".
- ✅ **The Taste Rules**:
  - **Typography**: Maximum 2 font families. Tight tracking (`letter-spacing: -0.03em` to `-0.05em`) on large display type.
  - **Color**: Strict 6-role palette with exactly ONE high-impact accent.
  - **Depth Layering**: Foreground text plane + Midground subject + Background atmospheric ground.
  - **Emotional Curve**: Plan the emotional progression (Intrigue ➔ Tension ➔ The Engineered Peak ➔ Resolution).
  - **Signature Move**: Every build must feature at least one bespoke interaction mechanism.
