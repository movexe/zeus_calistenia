# 🎨 OpenDesign Design Systems Catalog

This catalog contains pre-engineered design token specifications for instant application in any design task.

---

## 1. 🌌 Linear Dark (`linear-dark`)
* **Personality**: Sleek, technical, ultra-modern, precision engineering, developer tool vibe.
* **Canvas / Background**: `#08090C` / `slate-950`
* **Card / Surface**: `#111218` with `1px solid rgba(255, 255, 255, 0.08)` border
* **Primary Accent**: Electric Indigo / Violet (`#6366F1` / `#8B5CF6`)
* **Secondary Accent**: Cyan Glow (`#06B6D4`)
* **Text Hierarchy**:
  - Primary: `#F3F4F6` (White-slate)
  - Muted: `#94A3B8` (Slate 400)
  - Subtle: `#475569` (Slate 600)
* **Typography**: *Inter* or *Geist Sans* + *JetBrains Mono*
* **Special Details**: Hairline borders, ambient radial gradients (`blur-3xl`), micro-badges with 1px border.

---

## 2. 🏛️ Swiss Minimalist (`swiss-minimal`)
* **Personality**: Objective, typographic rigor, grid-focused, high contrast, timeless clarity.
* **Canvas / Background**: `#F8F9FA` (Off-white / Paper)
* **Card / Surface**: `#FFFFFF` with strict black hairline `1px solid #E5E7EB`
* **Primary Accent**: Swiss International Red (`#DC2626` / `#E11D48`) or Pure Black (`#000000`)
* **Text Hierarchy**:
  - Primary: `#0F172A` (Pure Ink)
  - Muted: `#475569`
  - Subtle: `#94A3B8`
* **Typography**: *Helvetica Neue*, *Inter*, or *Neue Haas Grotesk* (Heavy weights, tight tracking `-0.04em`)
* **Special Details**: Strong asymmetric columns, oversized numerals, generous whitespace, sharp 0px border radius.

---

## 3. ⚡ Neo-Brutalist (`neo-brutalist`)
* **Personality**: Raw, high-energy, playful, bold outlines, vivid retro-pop colors.
* **Canvas / Background**: `#FEFCE8` (Warm Cream) or `#FFFBEB`
* **Card / Surface**: `#FFFFFF` with thick `3px solid #000000` border & `4px 4px 0px #000000` hard shadow
* **Accents**: Acid Lime (`#BEF264`), Cyber Yellow (`#FACC15`), Hot Pink (`#F472B6`), Vivid Lilac (`#C084FC`)
* **Typography**: *Space Grotesk*, *Syne*, or *Archivo Black*
* **Special Details**: Hard offset box shadows (`box-shadow: 4px 4px 0px #000`), geometric badges, pill tags, bold marquee tickers.

---

## 4. 👑 Editorial Luxury (`editorial-luxury`)
* **Personality**: Sophisticated, refined, high-fashion, bespoke, architectural elegance.
* **Canvas / Background**: `#0D0D0D` (Obsidian) or `#FAF7F2` (Warm Linen)
* **Card / Surface**: Translucent tinted glass or warm ivory `#F4EFE6`
* **Primary Accent**: Champagne Gold (`#D4AF37` / `#C5A880`) or Warm Terracotta (`#C25E3E`)
* **Text Hierarchy**:
  - Primary: `#FAF7F2` (or Deep Espresso `#1A1615` on light)
  - Muted: `#A8A29E` / `#78716C`
* **Typography**: *Playfair Display*, *Cinzel*, or *Cormorant Garamond* (Serif display) + *Plus Jakarta Sans* (Clean body)
* **Special Details**: Delicate 0.5px borders, generous line heights (`leading-loose`), italic accents, serif quotes.

---

## 5. 🔮 Cyberpunk HUD (`cyberpunk-hud`)
* **Personality**: Sci-Fi, tactical interface, futuristic telemetry, holographic data.
* **Canvas / Background**: `#030712` (Void Black)
* **Card / Surface**: `rgba(15, 23, 42, 0.75)` with backdrop-blur and chamfered/clipped corners
* **Accents**: Neon Cyan (`#00F0FF`), Neon Magenta (`#FF0055`), Matrix Green (`#00FF66`)
* **Typography**: *Orbitron*, *Share Tech Mono*, *Chakra Petch*
* **Special Details**: Coordinate tags `[LAT: 45.2 N]`, crosshair grid markers, glowing scanlines, SVG geometric brackets.
